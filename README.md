# Venugopal's Portfolio

[Live site](https://venugopalr-portfolio.netlify.app/)

A personal portfolio website showcasing projects, skills, and contact information.

## Overview

This repository contains the source for my portfolio website. It highlights selected projects, technical skills, and ways to get in touch.

## View the Site

- Open the site locally by double-clicking [index.html](index.html) or serve it with a simple HTTP server:

```bash
python -m http.server 8000
# then visit http://localhost:8000 in your browser
```

## Features

- Responsive single-page portfolio
- Projects gallery and descriptions
- Contact information and social links
- Assets organized under the Assets/ folder

## Tech Stack

- HTML
- CSS
- JavaScript

## Customize

- Edit [index.html](index.html) to update content and structure.
- Replace images and other media in the `Assets/` folder.
- Update contact details in the contact section of `index.html`.

## Deploy

This site can be hosted on GitHub Pages or any static hosting provider. To use GitHub Pages:

1. Push your repo to GitHub.
2. In the repository settings enable GitHub Pages and select the `main` branch (or the branch you use).
